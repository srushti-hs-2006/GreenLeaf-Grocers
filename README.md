# GreenLeaf Grocers 🥬

## Project Overview

GreenLeaf Grocers is a web-based grocery store management system developed using Python, Flask, SQLite, HTML, CSS, and JavaScript. It simplifies grocery store operations through inventory management, billing, sales tracking, and reporting.

## Features

* User login with admin and cashier roles
* Product and inventory management
* Billing with multiple products
* Automatic stock updates after billing
* Dashboard with sales analytics
* Sales report export to CSV
* Automated testing with pytest

## Technologies Used

* Python
* Flask
* SQLite
* HTML and CSS
* JavaScript
* Pandas
* Pytest

## Installation and Setup

1. Clone or download this repository.

2. Open the project folder in a terminal.

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   `http://127.0.0.1:5000`

## Run Tests

```bash
python -m pytest -v
```

## Note

This project was developed for learning and grocery store management demonstration purposes. Configure credentials securely before deploying it for real-world use.
